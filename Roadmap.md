# Roadmap e Funcionalidades do Projeto

## **1. Reconhecimento e Conversão de Áudio**
- Speech-to-text feature

## **2. Modelo de Machine Learning**
- ML model: Treinar um modelo com a letra do usuário para uso futuro
- Ferramentas que estendem capacidades de IA:
  - OCR
  - Reconhecimento de handwriting

## **3. API e Integrações**
- Criar uma API para desenvolvimento de features e templates
- Monetizar a API
- Mercado de vendas de features e templates (com percentagem por transação)
- A API conecta o backend com a UI 

## **4. Chatbot e Documentação por Projeto**
- Cada projeto contém materiais (PDFs de estudo, etc.)
- Chatbot integrado para conversar sobre o conteúdo de cada projeto

## **5. Ferramentas Avançadas**
- Smart templates:
  - Router para identificar números/gráficos
  - Templates e parsing de JSON
- Editor de texto com extração automática de imagens
- Armazenamento de imagens extraídas
- AI-generated templates
- Embedding de documentos para acesso do LLM
- Criar uma tool para o LLM acessar documentos embedded

## **6 Features de Produtividade**
- Implementar Pomodoro timer
- Stats e streaks para incentivar o estudo
- Integração com ML model para análise de progresso
